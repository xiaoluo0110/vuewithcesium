# vuewithcesium

Cesium 三维 GIS Demo 展示平台（仅托管打包产物，不含源码）。

访问地址：https://xiaoluo0110.github.io/vuewithcesium/

## 更新方式

1. 在源码项目执行：`npm run build:gh-pages`
2. 将新的 `dist/`（可排除 `static/model` 大模型）覆盖本仓库内容
3. `git add -A && git commit && git push`

GitHub Pages：Settings → Pages → Deploy from a branch → `main` / `/ (root)`
